PROJECT: Economics of Tourism — Course Website
Author: Paulo Fagandini
Institution: Universidade Europeia, Bachelor in Tourism

=== WHAT THIS IS ===
A Quarto website that hosts lecture slide decks for a course on Economics of Tourism.
The site is rendered to HTML and published via the docs/ folder (GitHub Pages style).

=== TECH STACK ===
- Quarto (website + revealjs slides)
- R (ggplot2, dplyr, tidyverse, eurostat, patchwork, lubridate) for charts inside slides
- Custom SCSS theme (slides/custom.scss) and CSS (styles.css) for branding
- Output directory: docs/  (configured in _quarto.yml)

=== ROOT-LEVEL SOURCE FILES ===
_quarto.yml         — project config: type=website, output-dir=docs, navbar with Home + Material
index.qmd           — homepage (brief course description)
material.qmd        — table of contents listing all lectures with links to slides and PDFs
styles.css          — custom CSS for the HTML pages (not the slides)
images/             — logo.png, circularity_chart_0.html (interactive chart used in lecture 21)

=== SLIDES (slides/*.qmd) ===
Each file is a self-contained revealjs presentation rendered with embed-resources: true
(meaning all assets are bundled into a single HTML file, no external dependencies).
chalkboard is set to false on all files (incompatible with embed-resources).
Slides use a shared SCSS theme: slides/custom.scss.
slides/data_cache/  — cached .rds files from eurostat API calls (avoid re-downloading)

=== PDF FOLDER ===
PDF/  — pre-rendered PDF versions of each slide deck (one per lecture).
        Stored at root level and also mirrored inside docs/PDF/ after rendering.

=== OUTPUT FOLDER (docs/) ===
Generated by `quarto render`. Do not edit manually.
Contains: index.html, material.html, site_libs/ (Bootstrap, revealjs, quarto-html),
          images/, PDF/, search.json, and rendered slide HTML files inside slides/.

=== TYPICAL YAML FRONT MATTER (slides) ===
---
title: "..."
subtitle: "Lecture N: ..."
author: "Paulo Fagandini"
date: today
date-format: "YYYY"
format:
  revealjs:
    from: markdown+emoji
    theme: [default, custom.scss]
    transition: slide
    slide-number: true
    chalkboard: false        # must be false — incompatible with embed-resources
    scrollable: false
    footer: "Economics of Tourism | Lecture N"
    logo: ../images/logo.png
    width: 1600
    height: 900
    embed-resources: true
---

=== RENDERING ===
To render the full site:   quarto render
To render one slide deck:  quarto render slides/lectureNN-name.qmd
To preview locally:        quarto preview
